# pcaLab: Teaching, Inference, Robustness, and Advanced Principal Component Analysis

A unified framework for classical and advanced PCA, dimensionality
selection, permutation inference, bootstrap and subspace stability,
robust and nonlinear extensions, structured PCA, projection tours,
publication-ready graphics and tables, and progressive teaching of PCA
mathematics.

## Details

The package intentionally separates descriptive PCA from inferential
procedures, casewise from cellwise robustness, sparse loading models
from low-rank plus sparse matrix decomposition, and linear PCA from
generalized or nonlinear component models. See the package vignettes for
mathematical derivations, interpretation rules, model-selection
criteria, and validation guidance.
